# 100 Days of Machine Learning

A dump of all the Google Colab notebooks I have written while learning machine learning, data science and Python. Everything I have practiced and built along the way lives in this one repo.
The zip files contains more than 150 individual files.

## What's Inside

The notebooks cover these topics:

- **Python:** core Python practice and problem solving
- **Pandas:** loading, cleaning, filtering, grouping and merging data
- **Data processing:** handling missing values, encoding, scaling and feature engineering
- **Data science:** exploratory data analysis and visualization on real datasets
- **Machine learning:** training, evaluating and improving models with Scikit-learn
- **Mini projects:** end-to-end notebooks built on practice datasets

## Repo Structure

There are no folders. All the notebooks are `.ipynb` files stored directly in the repo.

## How to Use

1. Open any `.ipynb` notebook on GitHub.
2. Click **Open in Colab**, or download the file and upload it to [Google Colab](https://colab.research.google.com).
3. Run the cells from top to bottom. Some notebooks need the dataset uploaded first.

## Tools

Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, Google Colab, Jupyter Notebook
